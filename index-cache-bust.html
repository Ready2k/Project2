Getting Started

  1. Enter your OpenAI API key in the Settings tab
  2. Choose your preferred voice settings
  3. Click the microphone button to start speaking
  4. The AI will respond with both text and voice

Keyboard Shortcuts

  • Space - Start/Stop recording (when focused)
  • Esc - Cancel current recording
  • Tab - Navigate between interface elements

Troubleshooting

  • No microphone access: Check browser permissions
  • API errors: Verify your OpenAI API key is correct
  • No voice output: Check your speaker settings and TTS mode
  • Poor recognition: Speak clearly and check microphone levels
