Multi-Agent Orchestration Test

This test verifies that complex multi-step requests are properly handled by multiple agents working together.

Balance Check + Conditional Payment

USER: Hi, check my balance and if I have enough money pay £100 off my credit card bill
EXPECTED WORKFLOW:
1. BankingInfoAgent: Check account balance
2. Conditional Logic: If balance >= £100
3. PaymentsAgent: Process credit card payment of £100
4. Summary: Provide combined response

Transfer with Verification

USER: Transfer £500 from savings to checking if you can verify my identity first
EXPECTED WORKFLOW:
1. IDVAgent: Verify user identity
2. Conditional Logic: If verification successful
3. PaymentsAgent: Process transfer

Check Transactions + Report Fraud

USER: Check my recent transactions and if there's anything suspicious, report it as fraud
EXPECTED WORKFLOW:
1. BankingInfoAgent: Get recent transactions
2. Analysis: Check for suspicious activity
3. FraudAgent: Report if suspicious activity found
