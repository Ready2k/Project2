# Product Overview

This is an **AI-powered voice assistant for financial services customer support** featuring dual-mode operation (Batch & Streaming), real-time speech recognition, natural voice responses, and comprehensive customer persona management.

## Core Features

- **Voice-to-Voice Conversations**: OpenAI Whisper for speech-to-text, GPT for responses, TTS for voice output
- **Dual Operation Modes**: Traditional batch processing and real-time streaming conversations
- **Financial Services Focus**: Specialized for banking, payments, fraud detection, and identity verification
- **Agent-Based Architecture**: Domain-specific intelligent agents with AI-powered routing
- **Customer Persona Management**: JSON-driven customer profiles with UK banking context
- **Advanced LLM Management**: Configuration templates, performance metrics, and multi-environment support

## Target Use Cases

- Lost card reporting and immediate blocking
- Account balance and transaction inquiries
- Transaction disputes and fraud alerts
- Money transfers and payment assistance
- General banking customer support scenarios

## Technology Context

This is a **client-side web application** built with vanilla JavaScript, designed for demonstration and prototyping. It integrates with OpenAI APIs (Whisper, GPT, TTS, Realtime API) and uses UK banking terminology and GBP currency formatting.
